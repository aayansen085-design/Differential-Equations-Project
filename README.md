# Differential Equations Solver

## Project Overview
This project is an interactive mathematics application developed using Python and Streamlit. It introduces Ordinary Differential Equations (ODEs) and Partial Differential Equations (PDEs) and demonstrates selected analytical and numerical methods for solving differential equations.

## Features
- Introduction to ODEs and PDEs
- First-order differential equations
- Linear and Bernoulli differential equations
- Euler's numerical method
- Fourth-order Runge-Kutta method
- Introduction to Lagrange's and Charpit's methods
- Mathematical formulas and examples

## Technologies Used
- Python
- Streamlit
- SymPy
- NumPy
- Matplotlib

## Installation

Install the required libraries by running:

```bash
python -m pip install -r requirements.txt
```

## How to Run

Run the following command in the VS Code terminal:

```bash
python -m streamlit run ode_pde_solver.py
```

The application should open in your web browser.

## Project Purpose
The purpose of this project is to help mathematics students understand differential equations through formulas, examples, and numerical calculations.
